BIENVENIDO
==========

Este es un sistema funcional de firewall distribuido sobre una red
SDN simulada con arquitectura cliente-servidor.

Todo el código está listo para ejecutar. Solo necesitas:
  • Python 3.11+
  • pip (gestor de paquetes)
  • 3 equipos en red (o localhost para pruebas)


PRIMEROS PASOS (5 MINUTOS)
===========================

1. INSTALAR DEPENDENCIAS

   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt

2. EJECUTAR DEMO LOCAL (Windows)

   DEMO_LOCAL.bat

   O (Linux/Mac):

   bash DEMO_LOCAL.sh

3. ABRIR INTERFAZ WEB

   http://127.0.0.1:8000/static/index.html

ESTRUCTURA DEL PROYECTO
=======================

server/           ← FastAPI backend centralizado
client/           ← Cliente SDN replicable
traffic_gen/      ← Generador de tráfico para pruebas
interface/        ← Web UI (HTML/CSS/JS)
config/           ← Configuraciones por nodo
tests/            ← Scripts de prueba
requirements.txt  ← Dependencias Python


COMPONENTES PRINCIPALES
=======================

SERVIDOR (port 8000)
  • Gestiona reglas de firewall
  • Registra nodos clientes
  • Recibe y almacena eventos
  • Proporciona API REST + Web UI

CLIENTE (escucha UDP/TCP)
  • Descarga reglas cada 10 segundos
  • Evalúa paquetes localmente
  • Reporta eventos al servidor
  • Replicable en múltiples equipos

INTERFAZ WEB
  • Panel de reglas (crear, editar, eliminar)
  • Panel de nodos (estado en tiempo real)
  • Panel de eventos (log de actividad)
  • Polling automático cada 5 segundos

GENERADOR DE TRÁFICO
  • Envía paquetes UDP/TCP
  • Configurable (puerto, protocolo, cantidad, intervalo)
  • Para pruebas del sistema


CÓMO EJECUTAR EN RED LOCAL
===========================

Necesitas 3 terminales/equipos:

SERVIDOR (en PC escritorio, IP: 192.168.1.50)
  uvicorn server.main:app --host 0.0.0.0 --port 8000

CLIENTE 1 (en portátil)
  python client/client.py config/nodo1.json

CLIENTE 2 (en Mac o segundo PC)
  python client/client.py config/nodo2.json

GENERADOR (desde cualquier equipo)
  python traffic_gen/generator.py --dst 192.168.1.100 --port 9001 --proto udp --count 10

TROUBLESHOOTING
===============

Problema: "Connection refused"
Solución: Verifica IP servidor en config.json

Problema: Puerto 8000 en uso
Solución: Cambia --port en uvicorn

Problema: ModuleNotFoundError
Solución: pip install -r requirements.txt

Problema: Firewall bloquea puertos (Windows)
Solución: netsh advfirewall set allprofiles state off

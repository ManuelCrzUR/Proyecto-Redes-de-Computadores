5. Si action="report" → POST /events al servidor
6. UI → polling GET /events, /nodes, /rules cada 5s

PARA EMPEZAR:
-----------

1. INSTALACION:
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt

2. OBTENER IP SERVIDOR:
   ipconfig
   (busca IPv4 en tu red)

3. EDITAR CONFIGS:
   config/nodo1.json → server_ip = tu IP
   config/nodo2.json → server_ip = tu IP
   config/nodo3.json → server_ip = tu IP

4. EJECUTAR (en 3 terminales simultáneamente):
   Terminal 1: uvicorn server.main:app --host 0.0.0.0 --port 8000
   Terminal 2: python client/client.py config/nodo1.json
   Terminal 3: [abrir navegador] http://IP:8000/static/index.html

5. PROBAR TRAFICO:
   python traffic_gen/generator.py --dst 192.168.X.X --port 9001 --proto udp --count 10

NOTAS IMPORTANTES:
-----------------

• CORS habilitado en servidor → funciona desde cualquier origen
• Política por defecto: ALLOW (si no hay regla que coincida)
• Firewall Windows puede bloquear puertos → desactiva temporalmente
• TCP escucha en puerto+100 (si UDP=9001, TCP=9101)
• Wildcards: campo null en regla = "cualquiera"
• Prioridad: número entero, mayor = más prioritario
